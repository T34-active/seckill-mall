# Java 常见类型快速上手

目标：按清单**一个个认识类型**，能写赋值、打印、传参。  
每节结构：**Java 是什么 → TS 对照 → 易错点 → 项目里怎么用**。

本项目 Java 版本是 **8**（字节码 52.0），下面写法都按 Java 8。

---

## 0. 一分钟心智模型

| 概念 | Java | ≈ TypeScript |
|------|------|--------------|
| 变量要写类型 | `String name = "a";` | `let name: string = "a";` |
| 创建对象 | `new User()` | `new User()` |
| 空 | `null` | `null` |
| 列表 | `List<String>` | `string[]` |
| 没有联合类型写法 | 多用包装类 + null | `string \| null` |

Java 类型分两类：

1. **基本类型（8 个）**：不能为 `null`，名字小写
2. **引用类型**：`String`、包装类、`List`、自定义类… 可以为 `null`

## 类型总表（按这个顺序学）

### A. 八个基本类型

| # | 类型 | 大小 | 默认值 | 字面量例子 | ≈ TS | 一句话 |
|---|------|------|--------|------------|------|--------|
| 1 | `byte` | 8 位 | `0` | `100` | `number` | 很小的整数，少用 |
| 2 | `short` | 16 位 | `0` | `1000` | `number` | 短整数，少用 |
| 3 | `int` | 32 位 | `0` | `10` | `number` | **最常用整数** |

| 5 | `float` | 32 位小数 | `0.0f` | `1.5f` | `number` | 单精度，少用 |
| 6 | `double` | 64 位小数 | `0.0d` | `99.9` | `number` | **最常用小数** |

| 8 | `boolean` | — | `false` | `true` / `false` | `boolean` | 真假 |

## 1. `byte` / `short`（了解即可）

范围很小，日常业务几乎不用，知道有这两个就行。

```java
byte b = 100;
short s = 1000;
```

**TS：** 都是 `number`，没有单独的 byte/short。

---

## 2. `int` / `Integer`

```java
int count = 10;              // 基本类型，不能 null
Integer stock = 100;         // 包装类，可以 null
Integer empty = null;
```

**TS 对照：**

```ts
let count: number = 10;
let stock: number | null = 100;
```

**怎么选：** 循环计数用 `int`；实体字段、可能为空用 `Integer`。

项目例子：`Product` 的 `Integer stock`。

---

## 3. `long` / `Long`（你刚踩过的坑）

```java
long id = 1L;                // 字面量加 L = long
Long productId = 1L;         // long 自动装箱成 Long ✅
// Long bad = 1;             // ❌ int 不能直接给 Long
```

**TS：** 一般用 `number`；特别大才用 `bigint`（`1n`），和 Java 的 `L` 不是一回事。

**易错点：**

| 写法 | 结果 |
|------|------|
| `10` | `int` |
| `10L` | `long` |
| `(long) 10` | 把 int 转成 long |
| `Long x = 10;` | ❌ 报错：需要 Long，实际是 int |
| `Long x = 10L;` | ✅ |

项目例子：`Product` 的 `Long id`。

---

## 4. `float` / `double` / `Double`

```java
float f = 1.5f;              // 要加 f
double price = 99.9;         // 小数默认是 double
Double amount = 99.9;
```

**TS：** `number`。

金额生产环境更常用 `BigDecimal`；初学先会 `double` 即可。

---

## 5. `char` / `Character`（和 String 别混）

```java
char c = '秒';               // 单引号，只能一个字符
Character ch = 'A';
// char bad = '秒杀';         // ❌ 字符数过多
```

**TS：** `'秒杀手机'` 和 `"秒杀手机"` 都是 string；Java **不是**。

| Java | 含义 |
|------|------|
| `'A'` | `char`，一个字符 |
| `"秒杀手机"` | `String`，字符串 |
| `'秒杀手机'` | ❌ 编译错误 |

---

## 6. `boolean` / `Boolean`

```java
boolean ok = true;
if (!ok) {
    System.out.println("失败");
}
Boolean flag = null;         // 只有包装类才能 null；初学优先用 boolean
```

**TS：**

```ts
let ok = true;
if (!ok) console.log("失败");
```

---

## 7. `String`（最常用）

```java
String name = "秒杀手机";
String tip = "商品：" + name;
boolean same = name.equals("秒杀手机");  // 比内容用 equals，不用 ==
int len = name.length();
boolean empty = name.isEmpty();
```

**TS：**

```ts
const name = "秒杀手机";
const tip = `商品：${name}`;
const same = name === "秒杀手机";
```

**易错点：** 比内容用 `.equals()`；字符串用双引号。

---

## 8. `null`

```java
Long productId = null;
if (productId == null) {
    System.out.println("商品不能为空");
}

Integer qty = 2;
if (qty != null && qty > 0) {
    // 安全使用
}
```

记住：`int` / `long` / `boolean` 等基本类型 **不能** 赋 `null`。

---

## 9. 数组 `T[]`

```java
int[] stock = new int[]{10, 20};
stock[0] = stock[0] - 3;
int n = stock.length;
```

**TS：**

```ts
const stock = [10, 20];
stock[0] = stock[0] - 3;
```

长度创建后不能直接变长；可变用 `List`。

---

## 10. `List<T>`

```java
import java.util.List;
import java.util.ArrayList;

List<String> names = new ArrayList<>();
names.add("手机");
names.add("耳机");
String first = names.get(0);
int size = names.size();
```

| Java | TS |
|------|-----|
| `List<String>` | `string[]` |
| `add` | `push` |
| `get(i)` | `[i]` |
| `size()` | `.length` |

项目例子：`List<ProductVO>`、`List<OrderVO>`。

## 11. `BigDecimal`（金额，认识即可）

```java
import java.math.BigDecimal;

BigDecimal price = new BigDecimal("99.90");
```

项目例子：`Product` 的 `BigDecimal price`。先会声明和看到不慌，计算以后再学。

## 12. 方法签名怎么读

```java
public static boolean deduct(int[] stock, int amount)
```

| 词 | 意思 | ≈ TS |
|----|------|------|
| `public` | 外面能调用 | 类似导出可见 |
| `static` | 不用先 `new`，用类名调 | `static` 方法 |
| `boolean` | 返回类型 | `: boolean` |
| `deduct` | 方法名 | 函数名 |

实例方法（项目更常见）：

```java
public ProductVO getProduct(Long id)
```

≈ TS：`getProduct(id: number): ProductVO`  
调用：`productService.getProduct(1L)`。

## 13. 类、字段、get/set（和 Lombok）

```java
import lombok.Getter;
import lombok.Setter;

@Getter
@Setter
public class ProductPractice {
    private Long id;
    private String name;
    private Integer stock;
}
```

有了注解就不要再手写同签名的 get/set：

```java
ProductPractice p = new ProductPractice();
p.setId(1L);
p.setName("秒杀手机");
p.setStock(100);
System.out.println(p.getName());
```

`main` 入口：

```java
public static void main(String[] args) {
    // 从这里开始跑
}
```

## 14. 你现在的最小工具箱

按优先级：

1. `String`（双引号）
2. `int` / `Integer`，`long` / `Long`（记住 `L`）
3. `boolean`
4. `char`（知道单引号只能一个字）
5. `double`（了解）
6. `int[]`、`List<T>`
7. `null` 判断
8. `new` + Lombok get/set

注解（`@Entity`、`@GetMapping`）先当「标签」，和类型分开记。
